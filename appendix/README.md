# The Appendices — *AI Agentic Control Point*

*Version 2026-08-01 · pre-press. Tracks the manuscript of "AI Agentic Control Point." Where this file and a printed page disagree, this file is the corrected one.*

Everything in the book's appendices, in copyable form. You are here because the printed page told
you to be: selecting forty lines of text out of an e-reader is a fight, and out of a paper book it
is impossible.

Nothing here replaces reading the chapters. The chapters explain *why* the method works. These
files are the method itself, in the form you need to run it.

## What's in this folder

**`setup-prompt.txt`**
The setup prompt, alone, ready to paste. Fill in the bracketed lines with your own project's facts
and leave the rest exactly as written — particularly the `WHAT YOU MAY NEVER DO` block, which is
the first control point in your project.

**`appendices-a-e.md`**
The kit. Appendix A (The Four Questions), B (Architecture and Audit-Trail Checklist), C (Mission
Brief Template), D (The Seam Sign-off Procedure), and E (Running the Four Seams on a New Project).
This is the file to hand your agent alongside the setup prompt.

**`appendices-f-g.md`**
Supplementary. Appendix F (Failure-Mode Diagnostic Guide) and G (The Always-Scan List). Neither is
needed to start a project; both matter once one is running.

## The fastest way to start

1. Clone or download this folder.
2. Open `setup-prompt.txt` and fill in the `MY PROJECT` block.
3. Hand your agent that prompt plus `appendices-a-e.md`.
4. Read what comes back against Appendix E, Phase 1 — and sign nothing you have not checked
   yourself.

What an agent returns is a draft. It is not signed, nothing in it has passed a gate, and every
sign-off record in it should be visibly empty. If one isn't, the agent removed a decision rather
than saving you keystrokes, and the difference between those two things is the whole method.

## The rest of this repository

The folders above `appendix/` are the worked example the book builds: a real mission brief, real
role prompts, real signed seam records, and the application they governed. Point your agent here if
you would rather it copy a working shape than infer one from the templates.
